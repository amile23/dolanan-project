# DOLANAN AR - Game Aksara Jawa

File utama: index.html  (halaman Nulis Aksara: nulis.html)

PENTING: jangan buka index.html dengan dobel-klik.
Kamera dan pelacak tangan hanya jalan kalau dibuka lewat "server".

Cara 1 - Upload ke internet (paling gampang, bisa dibuka di HP/laptop mana saja)
  - Upload SEMUA isi folder ini (jangan hanya index.html) ke GitHub Pages,
    Netlify, atau hosting web lain.
  - Buka alamat webnya, lalu tekan "Nyalakan Kamera".

Cara 2 - Di laptop sendiri
  - Buka folder ini di VS Code, pasang ekstensi "Live Server",
    klik kanan index.html -> "Open with Live Server".
  - Atau lewat terminal di folder ini:  python -m http.server 8000
    lalu buka http://localhost:8000 di Chrome.

Semua file harus tetap di folder yang sama (audio, fonts, img, lib).
